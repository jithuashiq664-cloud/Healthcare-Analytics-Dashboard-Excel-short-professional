# 🏥 Hospital Data Dashboard

## 📌 Description

This project is a **Hospital Data Dashboard created using Microsoft Excel**.
It helps analyze hospital data using key metrics, PivotTables, and charts.

## 🎯 Objectives

* Analyze hospital data
* Track patient information
* Analyze hospital performance
* Understand different medical and patient-related trends
* Present data using an easy-to-understand dashboard

## 🛠️ Tools Used

* Microsoft Excel
* Excel Formulas
* PivotTables
* PivotCharts
* Data Visualization
